# A股情绪复盘 PDF UI 改版规格

日期：2026-08-30

## 目标

把当前 A 股情绪复盘 PDF 从“数据表格导出”改为“专业投研日报”版式。报告应先呈现结论，再展开证据，最后给出交易纪律和观察点。视觉风格要求克制、清晰、适合反复阅读，不做营销化封面。

## 版式结构

最终 PDF 使用横版 A4，分为四类页面：

1. 摘要页
   - 标题、日期区间、生成日期。
   - 四个核心摘要块：当前情绪状态、纪律后最高仓位、最强题材、主要风险。
   - 一条情绪路径：例如 `分歧 -> 主升 -> 主升 -> 高潮过热 -> 高潮过热`。

2. 市场情绪仪表盘页
   - 保留关键指标表，但缩减横向字段。
   - 强调涨停、炸板率、跌停、最高板、昨日涨停反馈、情绪分、状态、纪律。
   - 用颜色区分情绪状态：主升为绿色，分歧/退潮为红色，高潮过热为橙红色。

3. 题材和个股页
   - 每天展示 Top 5 题材，不再展示过长列表。
   - 每天展示关键个股，不超过 8 只。
   - 个股角色用标签呈现：`龙头`、`容量中军`、`低位补涨`、`中位股`、`风险票`。
   - 风险标签独立突出，避免埋在长文本里。

4. 交易纪律页
   - 单独列出每天的 `allow`、`reduce`、`block`。
   - 写清楚触发原因和下一步观察条件。
   - 明确说明报告不构成买卖建议。

## 视觉规则

- 使用统一中文字体，优先 `STSONG.TTF`，不可用时回退到系统中文字体。
- 主色采用深灰蓝，辅助色采用绿色、橙红、红色和中性灰。
- 页面背景保持白色，避免大面积深色底。
- 表格只用于密集指标；结论和风险使用摘要块或段落。
- 页眉显示报告名称，页脚显示页码。
- 不使用图标、装饰性渐变、阴影堆叠或复杂背景。

## 数据口径

不改变现有情绪引擎的数据计算逻辑。UI 改版只调整 PDF 呈现方式，继续复用：

- `market_dashboard`
- `theme_ranking`
- `stock_role_classification`
- `discipline_gate`

## 验证要求

改版后必须重新生成：

- `reports/market_reviews/2026-08-30-sentiment-review-2026-08-24-to-2026-08-28.pdf`

最低验证：

- 用 `pypdf` 确认 PDF 可抽取文本，且包含四个核心章节。
- 用 Poppler 渲染全部页面或至少关键页面。
- 视觉检查确认中文没有乱码、表格没有遮挡、标题和页面内容没有重叠。
- 运行 `git diff --check`。

## 范围边界

本次只优化 PDF 版式和可读性，不重写情绪评分算法，不改数据源，不新增交易建议逻辑。
