# Watchlist: 长鑫科技 / 长鑫存储 IPO

## Core Hypothesis

长鑫科技 IPO、招股书更新、问询回复、募投扩产、业绩预告、供应链采购和股权结构变化，可能带动 A 股影子股、半导体设备材料供应商、合肥本地国资平台和存储产业链重估。

## Primary Triggers

- IPO 状态变化：受理、问询、恢复审核、提交注册、注册生效、发行安排。
- 招股书或问询回复更新：营收、利润、募投项目、产能、供应商、客户、股东名单。
- 长鑫相关主体业绩预期、扩产、采购、技术节点变化。
- 合肥市/安徽省半导体、存储、战新产业政策或基金动作。
- A 股公司公告中出现长鑫、合肥长鑫、长鑫存储、CXMT、存储芯片、DRAM 相关订单/认证/送样/量产。
