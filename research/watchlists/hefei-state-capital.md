# Watchlist: 合肥国资 / 产业资本映射

## Core Hypothesis

合肥国资和产业资本在半导体、新能源车、显示、AI、机器人等方向的投资动作，可能通过 A 股本地平台、参股基金、供应链公司和影子股形成事件驱动机会。

## Primary Triggers

- 合肥市/安徽省重大产业基金设立、出资、增资、退出。
- 本地国资平台参与 IPO 公司股权、并购、定增或产业项目。
- 合肥重点产业企业 IPO、融资、扩产、重大订单。
- A 股公司公告披露与合肥国资、产业基金、建投、产投、兴泰、国资委相关交易。

## Sources To Check

- 合肥市国资委、合肥产投、合肥建投、兴泰资本公开信息。
- 安徽省/合肥市发改委、经信局、科技局政策发布。
- A 股公告中的交易对手、基金 LP/GP、关联方披露。

## Alert Priority

High when a local capital action directly连接 IPO、股权、重大投资、上市公司公告或可量化资金规模。
